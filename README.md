# Farland Tales · 远乡物语

基于 HTML5 Canvas 的牧场物语风格农场经营游戏，纯前端实现，双击 `index.html` 即可游玩。

## 玩法

### 种田
- 四季轮转（春/夏/秋/冬），每季 28 天
- 10 种作物，不同季节、不同生长周期
- 锄地 → 播种 → 浇水 → 收割，经典四步
- 肥料可缩短生长时间

### 设备
| 设备 | 占地 | 功能 |
|------|------|------|
| 洒水器 | 1×1 | 每日自动浇灌周围 5×5 地块 |
| 筒仓 | 3×3 | 增加仓库容量 +20 |

### 加工
| 机器 | 占地 | 功能 |
|------|------|------|
| 风干仓 | 1×1 | 放入原料风干产出成品（每日自动推进） |
| 石磨 | 2×2 | 消耗体力研磨原料 |
| 厨锅 | 1×1 | 选择配方直接烹饪，支持一键全部烹饪 |
| 堆肥桶 | 1×1 | 投入种子积累点数，满后产出肥料 |

### 其他
- 钓鱼 —— 四季节各有不同鱼类
- 商店 —— 购买种子和设备，金币实时显示在顶部栏
- 仓库 —— 管理与手持物品
- 出货箱 —— 批量出售获得金币
- 导出/导入存档，支持新开存档

## 项目结构

```
data/
  crops.js      # 作物定义（季节/生长天数/售价/种子价）
  items.js      # 物品定义（自动从 crops 生成种子+作物条目，手动定义设备与加工品）
  recipes.js    # 机器加工配方
js/
  equip.js   # 设备放置/拆除/每日处理（洒水器/筒仓）
  machines.js   # 机器 UI 与加工逻辑（风干仓/石磨/厨锅/堆肥桶）
  app.js        # 主模块：游戏状态、Canvas 渲染、UI 弹窗、事件绑定
index.html      # 入口：HTML 骨架 + CSS 样式
```

### 加载顺序

`crops.js` → `items.js` → `recipes.js` → `equipment.js` → `machines.js` → `app.js`

## 运行

```bash
# 方式一：直接打开
双击 index.html

# 方式二：本地服务器
npx serve .
# 或
python -m http.server 8000
```

## 存档

存档通过 `localStorage` 自动保存。导出/导入使用 JSON 文件格式。

## 技术栈

- 纯前端，零依赖
- Canvas 2D 渲染
- localStorage 存档持久化
